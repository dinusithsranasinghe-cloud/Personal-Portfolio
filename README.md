# Personal Portfolio Website 🚀

A modern, lightweight, and fully responsive personal portfolio designed to showcase my academic coursework, technical skills, and software development projects.

## ✨ Features
- **Responsive Layout:** Clean UI crafted with modern semantic HTML5 and CSS3.
- **Dynamic Greeting:** JavaScript-powered time-based greeting for visitors.
- **Smooth Navigation:** Sticky navbar with smooth anchor scrolling across sections.
- **Coursework & Skills Display:** Organized tables and badged skill tags.
- **Project Showcase:** Interactive project cards with custom hover animations.

## 🛠️ Built With
- **HTML5** - Semantic web structure
- **CSS3** - Custom styling, Flexbox, Grid, and smooth transitions
- **JavaScript (ES6)** - Dynamic UI logic and interactions
